# Sample Forensic Report PDF

This project includes a generated sample report PDF at:

- `assets/reports/sample-forensic-report.pdf`
- `public/assets/reports/sample-forensic-report.pdf`

## Regenerate

Run:

```bash
node scripts/generate-sample-report-pdf.mjs
```

The script rewrites both copies so the static site can serve:

`/assets/reports/sample-forensic-report.pdf`
